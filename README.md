# Traffic_crash_analysis_project
Data Analysis  and a Streamlit dashboard for Traffic Crash data
This project is the Traffic Crash Analysis for the Chicago Traffic Crashes Data set from the year 2020 to present. It has resulted in gathering new information, insights and patterns that can be identified based on the data set that has all Traffic Crash data for the city of Chicago, Illinois. This Analysis was done using Python and MySQL to derive the required business insights.

1) Create a Python Virtual environment and activate it:
   python -m venv venv
   venv\\Scripts\\activate
   
2) Install the required packages via the terminal command :
    pip install pandas sqlalchemy pymysql streamlit
   
3) Create a Database using Python and MySQL, read the dataset (Traffic_Crashes.csv - link:https://drive.google.com/file/d/1jAFsxF8ri--wYC1A-8k_Otdlf8xfcODN/view) and push it into the Database.
4) Run the Streamlit app with the command :
    streamlit run strlit.py
